# Tyd_Tek Cybersecurity Portfolio

Evidence-backed cybersecurity research and detection-design portfolio for a TRM Labs Global Investigator (Triage) application.

## Evidence standard

This repository separates **research reviewed**, **designed/prepared labs**, and **verified test results**. No lab below is represented as executed unless raw output, screenshots, or equivalent evidence is available. The reviewed Notion records contain no verified execution artifacts for the projects in this initial portfolio.
